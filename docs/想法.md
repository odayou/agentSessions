## 统一agent转交入口

把“转发到单个 CLI Agent 继续”做成轻量可选功能

把统一入口做成 SessionVault 的**可选操作入口**，而非核心调度层：

1. **从检索到操作。** 在会话详情页增加“在新 Agent 中继续此会话”按钮，调用对应 Agent 的 CLI 非交互模式，把当前会话上下文作为初始 prompt 传入。仅此而已，不做批量分发、不做状态同步。
2. **适配器复用。** SessionVault 已有的 Agent 检测和会话解析能力，可以直接复用来判断“哪些 Agent 可用”，然后调用其 CLI 的 `-p` 模式。Claude Code 的 `-p` 模式是官方支持的正规用法。
3. **不做调度，只做转发。** 用户发起后，工具就退出，剩下交给目标 Agent 自己管理。SessionVault 不跟踪执行状态，不接管权限，不管理沙箱。

<br />

<br />

## 引导用户使用统一入口的解决方案

推荐用户使用**Omnigent、AionUi、OpenHands、ORCH**、**LiteLLM Agent Control Plane** 等工具，来规避工具分散的局面，算是一种生态步道、本软件本身不需要做具体功能
