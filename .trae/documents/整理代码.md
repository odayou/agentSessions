# 代码整理方案

## Context

项目经历 M1→M4 多轮迭代（含"话题视图"删除、HTML 导出下线等回退操作），代码中积累了死代码、重复实现和结构瑕疵。本次整理目标：**在不改变现有功能行为的前提下**（唯一例外：删除已无 UI 入口的 HTML 导出，已与用户确认），清理死代码、消除重复、修复结构问题，让代码库回到干净一致的状态。

## 整理项

**A1. 修复 cli.js 结构问题** — [src/cli.js](file:///d:/AiCode/agentSessions/src/cli.js)

**A2. 删除 HTML 导出**（用户已确认） — [src/export.js](file:///d:/AiCode/agentSessions/src/export.js)、[server.js](file:///d:/AiCode/agentSessions/server.js)

- server.js `/api/export` 的 fmt 收敛为只接受 `md` / `json`

**A3. export.js 与 query.js 读取逻辑去重** — [src/export.js](file:///d:/AiCode/agentSessions/src/export.js)、[src/handoff.js](file:///d:/AiCode/agentSessions/src/handoff.js)

**A4. 提取 adapter 公共逻辑** — 新建 `adapters/lib.js`

  - workbuddy.js L198 死代码：`const cwdKey = normalizeCwd(cwd)` 计算后从未使用，连同其私有 `normalizeCwd` 一并删除
  - trae.js L108：`turns.find((t) => t.userMessage)` 连续调用两次 → 存变量调一次
- 不合并的部分：workbuddy 与 claude-code 的"事件流→轮次组装"循环虽有相似性但细节不同（事件类型/排序比较器/去重键），保持各自实现，避免引入回归
